# AI-200 Python Foundations

My hands-on Python learning notes and exercises while preparing for the Microsoft AI-200 certification.

This repository is for beginners learning Python by writing and running small programs—not just watching tutorials.

## What I’m learning

- Variables and data types
- Strings and f-strings
- Numbers and arithmetic
- Type conversion
- Conditional statements
- `for` and `while` loops
- Lists and collections
- Functions and error handling
- APIs, JSON, and environment variables

## Project structure

- `lesson_*.py` — small examples for each concept
- `task_*.py` — practice exercises I complete after each lesson

## Run an exercise locally

```bash
python3 lesson_01_variables.py
